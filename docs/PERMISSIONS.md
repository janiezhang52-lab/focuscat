# 专注猫咪的权限与系统交互

适用于 `0.2.0-beta.1`。正常使用专注计时、喂食和桌面猫咪，不需要授予录屏、辅助功能、输入监控、麦克风、摄像头或完全磁盘访问权限。登录启动由使用者主动选择。

| 项目 | 是否需要开启 | 应用如何使用 |
| --- | --- | --- |
| 登录 Mac 时启动 | 可选；首次安装不主动注册 | 只有在设置里开启后才向 macOS 注册。旧版已经注册的系统登录项会保留。 |
| 辅助功能与输入监控 | 不需要 | 不读取其他软件的界面或键盘输入；只处理小猫窗口内的点击、拖动，并读取当前鼠标坐标以判断点击穿透。 |
| 屏幕录制 | 不需要 | 读取屏幕尺寸与可用区域来放置小猫，不采集桌面画面或其他应用窗口。 |
| 麦克风与摄像头 | 不需要 | 猫叫声来自随包音效；应用不录音、不拍摄。 |
| 完全磁盘访问、桌面或文稿访问 | 正常功能不需要 | 专注进度、食物等默认保存在当前用户的应用支持目录。 |
| 系统通知 | 当前不请求通知授权 | 完成后更新应用文字并请求系统注意；当前没有通知中心横幅功能。 |
| 网络与账号 | 不需要 | 没有登录、云同步、遥测、广告或自动更新功能；源码未发现主动网络请求。 |
| 桌面显示 | 无需额外悬浮窗授权 | 通过应用自身的透明窗口显示；普通窗口会盖住小猫。 |

## 保存哪些数据

默认存档目录为 `~/Library/Application Support/FocusCat/`，包含专注进度、食物、饱腹、猫与饭碗位置、设置、最近游戏内操作记录及备用档。面板位置还由 macOS 的应用偏好设置保存；登录项由系统管理。

应用不上传这些数据。卸载默认保留存档。详细清理办法见[安装说明](INSTALL.md)，数据用途见[隐私说明](PRIVACY.md)。

## 安装验证不等于隐私权限

当前体验版使用临时签名（ad-hoc），没有 Developer ID 身份签名，未经过 Apple 公证。互联网下载后可能被 Gatekeeper 拦截。这属于安装来源验证，和录屏、辅助功能等隐私授权是不同事项。请按[安装说明](INSTALL.md)处理，不要为了运行小猫关闭系统整体安全保护。

## 说明的依据与范围

本表根据当前源码、实际应用包声明、签名与依赖检查整理。当前构建未启用 App Sandbox，因此不能把“代码目前不读取某类数据”理解为系统强制隔离或禁止访问。以上也不等于已经审计用户系统里授予的权限，不能保证所有 macOS 版本都没有任何系统提示。

制作演示截图时，Codex 或截图工具可能使用其自身的录屏、辅助功能能力；这不属于专注猫咪的使用要求。应用自带的显式开发导出参数只绘制自身画面或输出诊断文件，普通双击启动不会启用。
