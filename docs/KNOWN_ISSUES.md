# 已知问题与体验范围

适用于 `0.2.0-beta.1`。

- **系统与芯片**：安装包只有 arm64，面向 Apple Silicon Mac；系统目标为 macOS 13+，但目前仅做本机测试。Intel Mac、Windows 暂未支持，其他 Mac 和系统版本仍需要实际验证。
- **安装提示**：使用临时签名（ad-hoc），未经过 Apple 公证；互联网下载后的首次启动可能被 Gatekeeper 拦截，不能保证所有 Mac 都能通过“仍要打开”启动。请按[安装说明](INSTALL.md)处理。
- **动作衔接**：伸懒腰、趴卧、起身和行走之间可能出现短暂叠影或轮廓变化。部分转向使用镜像，尚未将全部动作重做为连续动画。
- **桌面显示**：小猫位于桌面层，普通窗口可以遮住它。小猫在启动时选定的一个屏幕上活动，不支持跨屏漫游；外接屏切换、Spaces 与全屏场景尚未完成兼容性验证。
- **计时恢复**：休眠、退出或异常长的运行中断会暂停专注，恢复后需要手动继续。强制退出可能丢失最后约 1 秒尚未保存的进度。
- **登录启动**：首次安装默认关闭，需要主动开启。移动应用位置后可能需要重新切换开关；不同 Mac 的登录项批准与重启行为尚待验证。
- **功能范围**：商店、换装、零食与睡垫尚未开放；没有云同步、自动更新或 Windows 版本。

遇到问题，请在 Issues 中选择 **Bug report**，填写步骤、预期结果、实际结果、应用版本、Mac 芯片及 macOS 版本。截图前请遮挡个人信息。如果系统提示应用已损坏或将损坏电脑，请停止打开并附上完整提示。
