# 隐私说明

适用于专注猫咪 `0.2.0-beta.1`。

专注猫咪在本机运行，不需要账号或网络。应用不包含分析统计、广告、云同步或自动更新功能，也不会向开发者上传数据。

## 本地保存的内容

应用在当前用户的 `~/Library/Application Support/FocusCat/` 中保存：

- 专注时长、当前计时状态和食物奖励进度。
- 食物数量、饱腹状态、尚未完成的喂食。
- 小猫与饭碗位置、静音和显示设置。
- 最近的游戏内奖励、喂食等操作记录及时间，以及备用存档。

这些文件不会随安装包分发，也不会由应用上传。面板位置还由 macOS 的应用偏好设置保存；登录项由系统单独管理。卸载应用默认保留存档；删除方式见[安装说明](INSTALL.md)。

## 系统交互

应用读取屏幕布局与当前鼠标坐标来放置、拖动桌面猫及判断点击穿透，并接收系统休眠、唤醒通知以暂停计时。它不读取桌面文件、其他应用中的键盘输入或其他应用内容，不使用摄像头或麦克风。详见[权限说明](PERMISSIONS.md)。

首次安装默认不启用登录启动；只有用户主动打开设置中的开关时，应用才请求 macOS 注册登录项。系统可能要求用户进一步允许。

macOS 自身可能执行下载来源、签名和恶意软件检查；GitHub 也会处理访问和下载请求。这些属于相应平台的服务，不是专注猫咪的数据上传功能。

## 反馈时的隐私

GitHub Issues 中的反馈可能公开可见。请只提供复现需要的信息，遮挡用户名、个人路径和桌面内容；无需上传完整存档或系统日志。应用不会自动发送崩溃报告。
