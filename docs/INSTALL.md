# 安装专注猫咪

## 确认设备

需要 Apple Silicon（M 系列芯片）Mac。macOS 13 或更新版本是本版的系统目标；目前仅做过开发用 Mac 的本机测试，未验证所有系统版本。Intel Mac 与 Windows 暂不支持。

在苹果菜单 →“关于本机”中可查看芯片和系统版本。

## 下载并安装

1. 打开本仓库的 **Releases**，选择 `0.2.0-beta.1`。
2. 下载 `FocusCat-0.2.0-beta.1-macOS-arm64.dmg` 或 `FocusCat-0.2.0-beta.1-macOS-arm64.zip`。
3. 使用 DMG 时，打开镜像，将“专注猫咪”拖入“应用程序”，再推出镜像。使用 ZIP 时，解压并将“专注猫咪.app”拖入“应用程序”。
4. 从“应用程序”打开“专注猫咪”。首次打开后，点击菜单栏的小猫图标即可找到面板。

若电脑已有旧版，先从旧版菜单栏选择“退出专注猫咪”，再替换应用。本版没有自动更新；后续版本需从 Releases 手动下载。替换应用不会主动删除本地存档，更新前可自行备份存档文件夹。

## 首次打开的系统提示

本体验版采用临时签名（ad-hoc），未经过 Apple 公证，因此下载后可能被 macOS 拦截。

若提示无法验证开发者或 Apple 无法检查 App，只有在确认下载来源可信、文件未被改动且愿意继续时，才按 Apple 提供的流程操作：先尝试打开 App，再进入“系统设置”→“隐私与安全性”，找到“仍要打开”，并在后续对话框确认。按钮可能因系统版本或管理员策略而不可用；不要修改系统整体安全策略。

**若提示“已损坏”“将损坏你的电脑”，或没有可用的“仍要打开”选项，请停止打开，在 Issues 中反馈完整提示和下载的文件名。** 不要执行移除隔离属性或关闭系统安全保护的命令。

参考：[Apple 官方：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。本说明核对于 2026-10-17。

## 可选：核对下载文件

同一 Release 附有 `SHA256SUMS.txt`。可以在“终端”输入以下命令及一个空格，再将下载的 ZIP 或 DMG 拖入终端，按回车：

```sh
shasum -a 256
```

将输出与 `SHA256SUMS.txt` 中同名文件的校验值逐字比较。校验值不同请停止安装，重新下载或反馈；校验值相同只说明文件与发布记录一致，不代表 Apple 已公证。

## 开始体验

1. 选好时长，点“开始专注”。切换到其他工作窗口后仍会计时。
2. 点“放入饭碗”，使用初次赠送的食物体验喂食。
3. 点击小猫或菜单栏图标重新打开面板。

关闭面板不会退出程序。菜单栏或设置中的“退出专注猫咪”会保存并退出。首次安装默认不启用“登录 Mac 时启动”，需要时可在设置中主动开启；已有系统登录项设置不会因为安装新包自动清除。

## 卸载

先在应用设置中关闭“登录 Mac 时启动”（如果曾开启），退出程序，再将“应用程序”中的“专注猫咪”移到废纸篓。本地存档会保留。

若还需要删除存档，可在 Finder 的“前往”→“前往文件夹”输入 `~/Library/Application Support/FocusCat/`，确认不再需要后自行删除。删除存档会清除专注进度、食物、位置和设置，且不能由应用恢复。
